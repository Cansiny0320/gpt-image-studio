# 最终图内存优化设计

2026-11-08 已批准。新请求强制关闭中间预览，历史设置仍可导入和复用。Worker 使用普通上游 JSON，只保留当前图片的一份二进制分块，完成校验后依次用于 R2 归档和浏览器回传。浏览器继续接收原有 NDJSON，图片内容、格式、ID、顺序、历史记录和下载行为保持一致。归档失败仍返回可下载的图片并标记失败。

- 使用能分段产出 JSON 字符串的 tokenizer，增量读取 `data[*].b64_json`。保留有效的现有响应格式及错误诊断；在确认当前图片对象结束前，不发布图片。保持 20 MiB 事件保护、19 MiB Base64 保护及浏览器上限。
- 图片数据分块解码，在 Worker 内复用这组字节。R2 以已知长度的流写入；D1 元数据和原有失败清理行为不变。NDJSON 按消费者需求逐块输出，每条记录完整后再处理下一张。浏览器读行也避免反复从头扫描。
- 不修改线上配置或存储，不扩大尺寸上限。用本地 Worker 和模拟上游复测单请求、同实例 2/4 并发、慢客户端、取消、截断、无效 Base64、多图和归档失败。
