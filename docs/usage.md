# 使用与数据保存

[返回 README](../README.md) · [English](usage.en.md)

在 [工作台](https://image.cansiny.top) 输入提示词并选择生成参数。图片编辑模式支持上传参考图以及遮罩或标注 PNG；生成结果可下载，也可继续编辑。历史记录中的图片、提示词和参数均来自当前浏览器。

API key 仅保存在服务端，生图请求经过 Worker，无需人机验证。可用模型和能力取决于站点 API 项目权限。

## 数据与限制

- 单次最多生成 3 张图片，SVG 仍限单张。
- 浏览器 IndexedDB：完整提示词、生成参数、最终图片 Blob 和时间。删除本地历史不会删除服务端档案，清理浏览器数据后无法从服务端找回。ZIP 备份可迁移历史；默认导出已加载记录，也可选择部分记录。
- D1：请求通过校验后保存提示词和所选生成参数，即使生图失败也会保留，并记录请求状态和必要图片元数据。R2：最终图片原始二进制文件。两者均不提供面向访客的历史读取或读图接口。
- 参考图、遮罩和标注只在当前请求中处理；中间预览不保存。不记录提示词、图片内容或 key 到日志。
- 编辑支持最多 16 张参考图；站点为 Workers 内存设置单文件 10 MB、总请求 24 MB 上限（界面预留开销限制为 23 MB）。单图片响应事件上限 20 MiB。这些是站点处理限制，不代表 OpenAI 的全部上传上限。
- 备份支持最多 256 MB 图片数据，较大历史请选择分批导出。浏览器可能清理站点数据，重要作品建议下载或导出。
- GIF 仅对 GPT Image 2.6 Flare / Sunburst 开放，支持帧数和帧间隔配置，默认自动尺寸；自定义尺寸失败时可切回自动或减少帧数；实际可用性取决于 API 项目权限。SVG 仍需服务端开启。SVG / GIF 不支持流式预览，SVG 仅支持单张文生图。SVG 以 `<img>` 显示，不插入 HTML。GIF 和 SVG 结果可下载，但不能直接用作栅格参考图继续编辑。
- 若连接中断，上游可能已经产生用量；不会自动重新生成。已收到的最终图仍可保存。服务端留档失败会明确提示，不丢弃已生成图片。
- 本地存储写入失败时保留内存副本供下载或重试保存。服务端存档不自动过期。

完整参数对照及实测范围见 [API 兼容性检查](api-compatibility.md)。
